# fixture-finder-data

Public data for the iOS app MVP Fixture Tools. It contains no app code.

## Contents

- `dataset-manifest.json` - current version, fixture count and the URL of the dataset file. The app reads it when you check for library updates.
- `ofl-runtime.json` - the compact fixture dataset, generated from the [Open Fixture Library](https://open-fixture-library.org/) (MIT licensed).
- `dataset-provenance.json` - sources, licences and counts of the dataset.
- `index.html`, `support.html` - privacy notice, legal notice and support page (served via GitHub Pages).
